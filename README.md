# support-ai-mcp

MCP-сервер для поиска по базе знаний и подсказкам 5SYSTEMS. Даёт ассистенту (Claude Desktop, Claude Code и другим MCP-клиентам) два инструмента поиска, которые обращаются к API 5Systems Support AI.

Сервер работает по stdio, ничего не слушает на портах и не требует ключей доступа — клиент запускает `support-ai-mcp.exe` как дочерний процесс.

## Инструменты

| Инструмент | Что ищет | Что возвращает |
| --- | --- | --- |
| `search_tips` | Внутренние подсказки техподдержки (коллекция `5s-tips`) | Заголовок и **полный текст** подсказки в markdown |
| `search_articles` | Статьи Базы знаний на 5systems.ru (коллекция `5s-doc-ollama`) | Заголовок и **ссылку** на статью, без текста |

Оба инструмента принимают один параметр `query` — вопрос на естественном языке — и возвращают не более 5 наиболее релевантных результатов. Если подходящего ничего не нашлось, возвращается пустой список: это штатный ответ, а не ошибка.

Как пользоваться инструментами в работе с заявками — см. [USAGE.md](USAGE.md).

## Настройка Claude Desktop

1. Склонируйте репозиторий к себе на компьютер и запомните путь до файла `support-ai-mcp.exe` — он уже собран, дополнительно ничего компилировать не нужно.

2. Откройте файл конфигурации Claude Desktop:
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`

3. Добавьте сервер в секцию `mcpServers`, указав полный путь до `support-ai-mcp.exe` из склонированного репозитория:

   ```json
   {
     "mcpServers": {
       "support-ai-mcp": {
         "command": "C:\\path\\to\\support-ai-mcp\\support-ai-mcp.exe"
       }
     }
   }
   ```

4. Перезапустите Claude Desktop. После перезапуска в списке инструментов должен появиться `support-ai-mcp` с инструментами `search_tips`, `search_articles`.

## Настройка Claude Code

```bash
claude mcp add support-ai-mcp -- C:\path\to\support-ai-mcp\support-ai-mcp.exe
```

Проверить подключение — командой `/mcp` в интерактивной сессии.

## Сборка из исходников

Исходный код лежит в `src/`. Готовый `support-ai-mcp.exe` лежит в корне репозитория, пересобирать его нужно только после правок в исходниках. Требуется Go 1.25 или новее:

```bash
go build -o support-ai-mcp.exe ./src
```

## Диагностика

- **Инструментов нет в списке после перезапуска** — чаще всего неверный путь в конфиге или не экранированы обратные слэши — в JSON путь пишется через `\\`.
- **Ошибка вида `HTTP error 5xx` или `unable to fetch ...`** — недоступен сервис `https://api.5systems.ru/support-ai/v1`. Сервер тут ни при чём, проверьте сеть и доступность API.
- **Постоянно приходит пустой результат** — сервер работает, но поисковый индекс не нашёл совпадений. Переформулируйте запрос по рекомендациям из [USAGE.md](USAGE.md).
